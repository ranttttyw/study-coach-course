# 课程版验证记录

验证日期：2026年10月17日。

## 环境

Linux，Python 3.12.14。实际安装版本：Streamlit 1.66.0、LangGraph 1.2.16、OpenAI SDK 2.54.0、Pydantic 2.14.1、python-dotenv 1.2.4。其余精确依赖见 uv.lock 和 requirements.txt。

项目声明支持 Python 3.11 到3.13；本次只在3.12验证，没有声称完成 Windows、macOS、其他 Python 版本或云平台矩阵测试。

## 已执行的检查

### 自动回归测试

命令：`uv run --frozen python -m unittest discover -s tests -v`

12项通过：

1. 生成阶段只生成，不执行评分。
2. 评分阶段复用原题，不重新生成题目。
3. 空答案被拒绝。
4. 超范围模型分数被拒绝。
5. 新建存储对象后仍可恢复档案。
6. 按编号过滤记录，删除只作用于当前编号。
7. 同一题目编号重复提交只写入一次。
8. 演示记录不进入真实在线评分均值。
9. 演示模式不输出模拟知识分数。
10. 演示进度助手返回可检查工具证据。
11. 模拟在线协议中工具结果被回传给模型。
12. 模型违反必需工具调用要求时拒绝无证据回答。

模拟在线测试不访问模型服务，只验证应用协议处理。

### 页面交互测试

命令：`uv run --frozen python scripts/check_ui.py`

使用 Streamlit AppTest 和临时数据库，验证七个交互检查点：启动、保存档案、生成与提交、原题快照一致、进度工具证据、切换编号、新会话恢复。全部通过。测试不写入使用者的真实学习数据库。

### 启动与文档

- 配置检查脚本通过，未发送真实模型请求。
- 本地 Streamlit 服务成功启动，健康检查端点返回成功。
